# **App Name**: Data Rush: Server Ascent

## Core Features:

- Data Icon Control: Allow the player to control a data icon, moving it left or right to avoid obstacles and collect bits.
- Infinite Server Tower Generation: Generate an endless series of server modules (platforms) with varying gaps and obstacle placements.
- Obstacle Avoidance: Implement various obstacles (firewalls, viruses) that the player must dodge to survive.
- Bit Collection: Scatter collectible bits throughout the server tower for the player to gather, increasing their score.
- Score Tracking: Display the player's score based on bits collected or height reached.
- Dynamic Difficulty Adjustment: Leverage generative AI to analyze player performance and tool the adjustment of obstacle frequency and platform spacing for ongoing challenge and engagement.

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) to represent data and technology. Based on the concept of data being digital.
- Background color: Dark gray (#333333) to mimic a server room environment.
- Accent color: Electric green (#39FF14) to highlight collectibles and interactive elements. Green complements blue on the color wheel, while differing strongly in brightness and saturation.
- Body and headline font: 'Space Grotesk' sans-serif font to create a computerized, techy feel suitable for the game.
- Use simple, pixel-art-style icons for the data icon, obstacles, and collectibles.
- A vertical layout with the player starting at the bottom and ascending the server tower.
- Simple animations for the data icon movement, obstacle movement, and bit collection.
